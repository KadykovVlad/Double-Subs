# Этап 11. Ревью перед бетой

Ревью сделано вручную по всему коду (проект не git-репозиторий, поэтому скиллы `code-review` и `security-review`, которые работают с git-диффом, не применялись). Проверялись: права, обмен сообщениями, внедрение HTML, обработка данных страницы, утечки данных, зависимости, устойчивость.

## Найдено и исправлено
| # | Важность | Что | Исправление |
|---|---|---|---|
| 1 | Средняя | Прототипная страница `translator-frame.html` была доступна **любому сайту** (`web_accessible_resources: <all_urls>`): сайт мог встроить её и узнать, что расширение установлено, и его ID | В сборке для магазина её нет вообще: ни ресурса, ни страниц лаборатории и диагностики (`filterEntrypoints`, флаг `__DS_PROTOTYPES__`); остаются только в dev- и e2e-сборках |
| 2 | Средняя | На YouTube адрес субтитров берётся из ответа плеера, который пишет страница; поддельный адрес увёл бы токен `pot` на чужой сервер | `buildTrackUrl` отказывает всему, что не `https://*.youtube.com`; тесты на чужой домен, похожий домен и http |
| 3 | Низкая | Озвучка без выбранного голоса могла взять **онлайн-голос** Chrome: слово ушло бы на сервер | Без выбора берётся только встроенный голос системы (`pickLocalVoice`); онлайн-голос только по явному выбору пользователя (описано в политике) |
| 4 | Низкая | Фон принимал любые сообщения `speak`/`translation` без проверки формы и размера | Проверка типа, длины, языка, лимитов (`isValidSpeakMessage`, `isValidTranslationRequest`), тесты |
| 5 | Низкая | Автопоиск на знакомом сайте обходил всю страницу каждые 1,5 с и при ошибке повторял без паузы | Быстрая проверка `<video>`, полный обход редко; после ошибки пауза 10 с |
| 6 | Низкая | В манифесте не было минимальной версии Chrome | `minimum_chrome_version: 138` (Translator API) |

## Проверено, замечаний нет
- Внедрение HTML: текст субтитров и слов везде через `textContent`; в `innerHTML` попадают только константы и значения настроек, которые проходят проверку формата (цвет `#rrggbb`, значения из списков).
- `eval`, `new Function`, удалённый код: нет. Сообщения между мирами (`postMessage`) на YouTube проверяют `event.source` и метку источника; страница может подделать такое сообщение и подсунуть свой список дорожек, но после исправления №2 не может увести токен.
- Зависимости: `npm audit --omit=dev` — 0 уязвимостей (в продукте только Preact).
- Данные: ничего не уходит на наши серверы (их нет); кэш переводов в IndexedDB расширения (страница не может его прочитать), ограничен 200 записями.
- Утечки: см. этап 10 (тест на 46 серий подряд).

## Права и их обоснование для магазина
| Право | Зачем |
|---|---|
| `activeTab` | Запуск на странице только по клику на значок |
| `scripting` | Внедрить скрипт в плеер, зарегистрировать автозапуск на знакомых сайтах |
| `storage` | Настройки, сохранённые слова, список сайтов |
| `offscreen` | Скрытая страница, где работает переводчик Chrome и кэш (в сервис-воркере его нет) |
| `tts` | Озвучка слова при наведении |
| `sidePanel` | Боковая панель вместо всплывающего окна (этап 12) |
| `*://*.youtube.com/*` | Постоянный доступ: субтитры YouTube не лежат в `<track>` |
| `optional_host_permissions: *://*/*` | Запрашивается по одному сайту, по клику пользователя (плеер в чужом iframe, автозапуск). Целиком — только если пользователь сам включил «Узнавать мои сайты на других адресах»: тогда крошечный скрипт `auto-probe` сравнивает адрес страницы со списком пользователя и больше ничего не делает; агент запускается только на совпадении (проверяется ещё раз в фоне) |
